# AWS Cloud Vault

## Overview
A Python project that uses AWS S3 to store, upload, and recover files in the cloud.

## Technologies
- Python
- AWS S3
- Boto3
- GitHub

## Features
- Upload files to AWS S3
- View S3 buckets
- List stored files
- Recover files from cloud storage

## What I Learned
- How to work with AWS S3
- How to use Boto3 to connect Python with AWS
- How cloud storage works
- How to automate cloud tasks with Python
